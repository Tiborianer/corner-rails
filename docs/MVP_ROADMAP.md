# MVP and post-MVP priorities

## Implemented vertical slice

1. Responsive Sites/Vinext shell, Germany selection, fixed R3F orthographic diorama, free-platform tutorial, first automatic DMU, and exact 10-coin fare.
2. Deterministic economy, active cleanliness, Station Rating, shared development cap, confirmation/undo protection, four platform upgrades, four length upgrades, six station systems, tier progression, and Tier 5 unlimited development.
3. Eighteen scheduled Germany definitions and twenty optimized GLB train heads, with modular procedural coaches for authentic relative consist lengths.
4. ICE-S and BR 01 events with distinct presentation, rewards, audio cues, temporary rating boosts, and deterministic debug triggers.
5. Missions, 15-minute day/night cycle, seasons, rain, 1×/2×/3× speed, Web Audio, prestige, and integrity-checked manual save codes.
6. Desktop/mobile HUD, keyboard shortcuts, mute, reduced-motion support, source-linked train requirements, automated logic tests, and screenshot QA.

## Next production pass

1. Add richer train-specific car geometry, bogies, pantographs, doors, window rhythms, LODs, and texture compression while preserving the current budgets.
2. Add broader audio layers: continuous rail hum, rain ambience, multiple horns/chimes, and per-event stingers.
3. Expand missions and event scheduling, add an explicit event countdown, and complete longer economy play-balancing sessions.
4. Add China, France, and Japan only after each roster is independently verified and balanced.
5. Add BR 50 or another preserved German steam variant, more events, and the deferred second-station expansion.

## Explicitly out of scope

- Backend accounts, automatic persistence, local storage, cloud saves, offline income, multiplayer, a scrolling world map, a free camera, public deployment, or downloadable third-party train models.
