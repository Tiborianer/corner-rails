# Final three-step onboarding

1. **Place your free platform.** Choose Germany, then select the highlighted gold platform slot. Your first station structure costs nothing.
2. **Welcome the first local train.** A one-car DB Class 650 arrives automatically, dwells, departs, and pays exactly 10 coins. Trains never need to be called manually.
3. **Develop three times, then tier up.** Spend three shared development uses on platforms, length, systems, or amenities. Cleanliness is separate: use the paid Clean Station button whenever dirt begins reducing Station Rating.
